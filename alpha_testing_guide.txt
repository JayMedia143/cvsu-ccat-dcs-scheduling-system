## 📈 Alpha Testing Optimization Roadmap

| Test ID | Optimization Phase | Description | Key Metric |
| :--- | :--- | :--- | :--- |
| **TC1** | **Base GA** | Standard GA with O(N^2) conflict scanning and blind random mutation. | Baseline Speed |
| **TC2** | **Bitmask Caching** | Uses Hash Maps to cache room/faculty availability for faster lookup. | Reduced Latency |
| **TC3** | **Matrix Engine** | Replaces all scans with O(1) Pre-allocated Feasibility Matrices. | >100x Speedup |
| **TC4** | **Selection Tuning** | Implements Tournament Selection (K=3) to increase selection pressure. | Faster Convergence |
| **TC5** | **Diversity Scaling** | Implements Adaptive Mutation to escape stagnation plateaus. | Stagnation Control |
| **TC6** | **Penalty Balancing** | Introduces Weighted Penalties to prioritize Faculty/Room constraints. | Quality Stability |
| **TC7** | **Heuristic Seeding** | Intelligent Population Initialization using First-Fit Matrix search. | Smart Start (Gen 0) |
| **TC8** | **Guided Mutation** | Heuristic Repair mutation that uses Matrices as a "Map" to find holes. | Zero-Conflict Goal |

## 🔬 Scientific Observations (Thesis Chapters 4-5)

1. **The 109 Plateau**: Identified a critical stagnation point at 109 conflicts caused by keyword mismatches ('Laboratory' vs 'Lab') and "Blind Thrashing." Resolved via TC8 Guided Mutation.
2. **Computational Speedup**: Transitioning from O(N^2) scanning (TC1) to O(1) Matrix indexing (TC3) resulted in a near-instantaneous fitness calculation, allowing for 50,000 generations in under 3 minutes.
3. **The Power of Seeding**: TC7 proved that starting with a "Smart Initial Population" reduces the evolutionary workload by over 70% right from Generation 0.
