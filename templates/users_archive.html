User Recycle Bin Guide
1. RESTORING USERS

Mistakenly deleted a user account? Use the Green Restore icon (left arrow) to bring it back to the active list instantly.

2. PERMANENT DELETION

The Trash-Fill icon will permanently erase the user account and all its data. Warning: This action cannot be undone and will remove all associated records.

3. 30-DAY RETENTION

Items in the trash are monitored. If a user account has been deleted for more than 30 days, a red 'Overdue' badge will appear.

4. SEARCH & BULK ACTIONS

Use the Search Bar to find specific usernames or roles. You can also select multiple items using Checkboxes to restore or delete them all at once.

5. SORTING OPTIONS

Organize your view using the Sort Dropdown. You can toggle between Newest to see recent deletes or Alphabetical order.

6. Pagination

Navigate between pages using the Page Numbers or the Previous/Next buttons at the bottom. For larger lists, enter a page number into the 'Jump to' box to go there instantly. You can also use your keyboard's Left/Right arrow keys to flip through pages.
