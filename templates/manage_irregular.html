Irregular Students Guide
1. Adding Irregular Students

Click 'Add Irregular Student' to either select an existing regular student or create a new irregular record. Once added, they will appear in this list for specialized scheduling handling.

2. Schedule Finder

Click the Puzzle icon on a student's row to open their individual Schedule Finder. This tool scans the entire master schedule to find valid, conflict-free subject combinations based on the student's required courses.

3. Batch Processor

Select multiple students and click the Puzzle icon in the green bulk bar to run the Batch Schedule Finder. This allows you to search for available schedules for several students simultaneously, significantly speeding up the process.

4. Finding & Sorting
  • Search Bar: Type any part of a student's name or ID; the list will update instantly as you type.
  • Funnel Icon: Click this to filter the list by Year Level or original Home Section.
  • Sort Menu: Arrange the list by Name (A-Z), Student ID, or Sections using the top-right dropdown.
5. Managing & Mass Actions

Individual actions are available on each row. For batch handling:

  • Calendar Icon: View the student's current real-time schedule.
  • Puzzle Icon: Open the Schedule Finder for this specific record.
  • Person-Dash Icon: Click this to Remove Irregular Flag. The student will be returned to the regular masterlist.
  • Bulk Actions: Select multiple rows to either run the Batch Schedule Finder or remove the irregular status from all selected students at once.
6. Pagination

Navigate between pages using the Page Numbers or the Previous/Next buttons at the bottom. For larger lists, enter a page number into the 'Jump to' box to go there instantly. You can also use your keyboard's Left/Right arrow keys to flip through pages.
