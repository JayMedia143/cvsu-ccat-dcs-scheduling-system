Constraint Checker Guide
1. WHAT IS THIS AUDIT?

This tool performs a real-time audit of the generated schedule. It checks every single class row against the university's 40 core rules to ensure there are no physical impossibilities or quality regressions.

2. COLOR-CODED STATUS

Fully Compliant (Green): Pure perfection. Soft Warnings (Yellow): Valid schedule, but some preferences weren't met. Attention (Red): Contains Hard Conflicts that must be resolved.

3. VIOLATION LEVELS

HC (Hard): Non-negotiable errors like room overlaps. SC-I / SC-II (Soft): Pedagogical goals like "avoiding 7:00 AM classes" or "limiting daily teaching hours".

4. FINDING & SORTING
  • Search Bar: Type a rule name, subject code, or section to filter the report instantly.
  • Funnel Icon: Filter the list by Violation Type (HC/SC) or by specific Departments.
  • Sort Menu: Arrange the list alphabetically by Rule Name for easier grouping.
5. DETAILED REPORTS

Each row shows the exact "Class A" vs "Class B" collision. It includes the Room, Day, and Time involved so you can jump back to the Schedule Editor to fix the specific issue manually if needed.

6. PAGINATION

Navigate between pages using the Page Numbers or the Previous/Next buttons at the bottom. For larger lists, enter a page number into the 'Jump to' box to go there instantly. You can also use your keyboard's Left/Right arrow keys to flip through pages.
