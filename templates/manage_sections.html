Sections Management Guide
{% if session.get('role') in ['admin', 'superadmin'] %}
1. Creating New Sections

Click the 'New Section' button at the top right to add a student block. Enter the name (e.g., BSCS 1-1), year level, and population. Use the Pencil icon in the table to edit these details later.

2. Assign Curriculum

To add subjects, select one or more sections by clicking their rows. When the green bar appears at the top, click the 'Assign Curriculum' button to choose subjects for those sections. You can use the Smart Presets (BSCoS/BSIT) to instantly select all subjects for a specific year and semester.

3. Copy & Paste Subjects

Click the Clipboard icon (Copy subjects) on a section to copy its assigned list. Then, select other sections and click the 'Paste subjects' button in the green bar to apply them instantly.

4. Finding & Sorting
  • Search Bar: Type any part of a section name; the list will update instantly as you type.
  • Funnel Icon: Click this to filter the list by Year Level (1st to 4th Year).
  • Sort Menu: Arrange sections by Name (A-Z) or Year Level using the dropdown on the top-right.
5. Managing & Mass Actions

Each row has icons for individual actions. To handle many sections at once:

  • Calendar Icon: View the real-time Schedule for that specific section.
  • Pencil Icon: Edit the section's name, population, or year level.
  • Trash Icon: Move the section to the Recycle Bin.
  • Bulk Actions: Click any row to select it (or the Header box to Select All). Use the Green Bar to bulk-delete sections to the Recycle Bin.
6. Pagination

Navigate between pages using the Page Numbers or the Previous/Next buttons at the bottom. For larger lists, enter a page number into the 'Jump to' box to go there instantly. You can also use your keyboard's Left/Right arrow keys to flip through pages.
