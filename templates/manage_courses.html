Course Management Guide
{% if session.get('role') in ['admin', 'superadmin'] %}
1. Creating New Courses (Manual)

Click the green 'New Course' button to add a single subject. You will need to fill in the Course Code (e.g., COSC 101), Full Name, and Department. You must also specify the Lecture/Lab units and Weekly Hours (Sync/Async) so the system knows how much time is needed for scheduling.

2. Bulk Importing from Curriculum

Instead of adding subjects one by one, use the Import buttons:

  • PDF Import: Best for standard curriculum files; the system scans the text to extract subjects automatically.
  • Word Import: For most reliable results, click this button and use the 'Download Template' link inside. Fill out that file and upload it back to the system.
3. Assigning Departments

Click the 'Dept. Assignment' button (with the diagram icon) to manage which departments "own" specific subjects. This ensures that only the correct department handles the scheduling for those courses.

4. Finding & Sorting
  • Search Bar: Type any part of a code or name; the list will update instantly as you type.
  • Funnel Icon: Click this to filter the list by a specific Department or common Subject Code (like Math or COSC).
  • Sort Menu: Use the dropdown on the top-right to arrange subjects by Newest, Alphabetical (A-Z), or by Department name.
5. Managing & Mass Actions

Each row has icons for individual actions. To handle many rows at once:

  • Calendar Icon: View the real-time Schedule for that specific subject.
  • Pencil Icon: Edit the subject's details (Code, Name, Units, etc.).
  • Trash Icon: Move the subject to the Recycle Bin.
  • Bulk Actions: Click any row to select it (or the Header box to Select All). Use the Green Bar to bulk-delete subjects to the Recycle Bin.
6. Pagination

Navigate between pages using the Page Numbers or the Previous/Next buttons at the bottom. For larger lists, enter a page number into the 'Jump to' box to go there instantly. You can also use your keyboard's Left/Right arrow keys to flip through pages.
