Room Management Guide
1. CREATING NEW ROOMS

Click 'New Room' to add a record. Enter the Room Name, Building, Capacity, and Functional PCs. Specify if it is a Lecture or Laboratory and set Department Access if needed. Use '+ T.B.A.' for fallback rooms.

2. SPECIAL COURSE ASSIGNMENT

Click the Pin icon to assign specific courses that must be exclusively scheduled in this room. This ensures that specialized subjects always use the correct laboratory equipment.

3. MONITORING STATUS
  • Available: The room is active and ready to be used by the scheduler.
  • Maintenance: The room is offline. The system will automatically skip this room during schedule generation to avoid conflicts.
4. FINDING & SORTING
  • Search Bar: Type any part of a room name or building; the list will update instantly as you type.
  • Funnel Icon: Click this to filter the list by Building or Status.
  • Sort Menu: Arrange rooms by Name (A-Z) or Capacity (High-Low) using the top-right dropdown.
5. MANAGING & MASS ACTIONS

Each row has icons for individual actions. To handle many rooms at once:

  • Calendar Icon: View the room's real-time Schedule.
  • Pencil Icon: Edit the room's name, capacity, or capabilities.
  • Trash Icon: Move the room record to the Recycle Bin.
  • Bulk Actions: Select rows or use the Header box to Select All, then use the Green Bar to bulk-delete to the Recycle Bin.
6. PAGINATION

Navigate between pages using the Page Numbers or the Previous/Next buttons at the bottom. For larger lists, enter a page number into the 'Jump to' box to go there instantly. You can also use your keyboard's Left/Right arrow keys to flip through pages.
