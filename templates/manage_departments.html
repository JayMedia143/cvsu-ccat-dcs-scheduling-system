Department Management Guide
1. CREATING DEPARTMENTS

Click 'New Department' to add a record. Enter the Department Name and an optional Code (e.g., 'DCS'). These codes are used system-wide for filtering faculty, rooms, and students.

2. ORGANIZATIONAL HIERARCHY

Departments act as the primary filter for other system data. Ensure names are accurate, as they directly impact the filtering options available in the Faculty, Rooms, and Students modules.

3. RECYCLE BIN

Deleted departments are moved to the Recycle Bin instead of being permanently erased. Click the 'Recycle Bin' button at the top-right to view, restore, or permanently delete archived records.

4. FINDING & SORTING
  • Search Bar: Type any part of a department name or code; the list will update instantly as you type.
  • Sort Menu: Arrange the list by Name (A-Z), Code (A-Z), or Newest using the top-right dropdown.
5. MANAGING & MASS ACTIONS

Each row has icons for individual actions. To handle many records at once:

  • Pencil Icon: Edit the department's name or code for accuracy.
  • Trash Icon: Move the department record to the Recycle Bin.
  • Bulk Actions: Select rows or use the Header box to Select All, then use the Green Bar to bulk-archive.
6. PAGINATION

Navigate between pages using the Page Numbers or the Previous/Next buttons at the bottom. For larger lists, enter a page number into the 'Jump to' box to go there instantly. You can also use your keyboard's Left/Right arrow keys to flip through pages.
