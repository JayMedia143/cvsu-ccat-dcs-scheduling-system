Layout Settings Guide
1. LAYOUT TYPES & TABS

Use the Left Sidebar to switch between different schedule document types (Course, Section, Faculty, Room). Each tab maintains its own independent set of templates and settings.

2. TEMPLATE MANAGEMENT

Upload .xlsx files to set the visual base for your schedules. You can Preview the current template to see cell mappings or Delete it to upload a fresh version.

3. PAPER SIZE & MARGINS

Select your preferred paper size (e.g., A4, Legal) and adjust margins in inches. These settings directly affect the View Page scaling and layout alignment.

4. IMAGE CALIBRATION

Fine-tune the placement of logos/seals from your Excel template. Adjust **X/Y Offsets** for position, **Scale** for size, and **Z-Order** to determine if images appear above or below the text grid.

5. HEADER & SIGNATORIES

Customize institutional details (Campus, Address, Contact) and set the display names and titles for the Signatory Blocks used in the printed schedules.

6. AUTO-FILLED FIELDS

Fields marked with a dashed border (Gray background) are auto-populated during the actual export process and cannot be manually edited here.
