Reports & Analytics Guide
1. ANALYTICS OVERVIEW

This dashboard provides live data on system performance, specifically tracking how many classes are scheduled and how efficiently your campus rooms are being utilized.

2. SYSTEM STAT CARDS

The Classes card shows the total number of approved schedule blocks. The Utilization card displays the global percentage of room usage across all active days.

3. BULK EXPORT TOOLS

Use the Excel Download form to generate complete schedule reports. Select your Semester and Report Type (Sections, Faculty, or Rooms) to download a formatted spreadsheet.

4. ROOM UTILIZATION

The table breaks down usage per room. Hours Used counts actual scheduled time, while Available reflects the system's operating capacity (e.g., 7am-7pm, 6 days/week).

5. COLOR INDICATORS

The progress bars use color-coding: Green for healthy usage (<50%), Yellow for high demand (50-80%), and Red for critically saturated rooms (>80%).

6. LIVE DATA REFRESH

Reports are generated in real-time. Any changes made in the Schedule Editor or Proposal Hub are reflected here immediately upon refreshing the page.
