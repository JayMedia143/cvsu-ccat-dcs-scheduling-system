Locked Schedules Guide
1. LOCKING SCHEDULES

Click 'Add Locked Schedule' to fix a class in the timetable. Select one Course, one Faculty, and one Room from the lists. Then, choose the target Sections and the desired Day/Time.

2. MULTI-SECTION BATCHING

You can lock a single course-room-faculty combo for multiple sections at once. Use the Year Level Filters (1st to 4th Year) and the 'Select Visible' button to quickly assign large batches of sections to a common slot.

3. GA SCHEDULER IMPACT

Locked schedules are mandatory. The Genetic Algorithm (GA) will place these classes first and build the rest of the timetable around them. Use this for subjects with strictly fixed venue or time requirements.

4. FINDING & SORTING
  • Search Bar: Type any part of a course code, section, or faculty; the list updates instantly as you type.
  • Sort Menu: Arrange the list by Course (A-Z) or Section (A-Z) using the top-right dropdown.
5. MANAGING & MASS ACTIONS

Individual locked schedules can be removed if they are no longer fixed:

  • Trash Icon: Move a locked schedule to the Recycle Bin. This "unlocks" the slot, allowing the GA to move it during the next generation.
  • Bulk Actions: Select multiple rows or use the Header box to Select All, then use the Green Bar to bulk-archive.
6. PAGINATION

Navigate between pages using the Page Numbers or the Previous/Next buttons at the bottom. For larger lists, enter a page number into the 'Jump to' box to go there instantly. You can also use your keyboard's Left/Right arrow keys to flip through pages.
