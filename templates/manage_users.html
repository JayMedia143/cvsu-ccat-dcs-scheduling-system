User Management Guide
1. Creating New Users

Click the 'New User' button at the top right to add a system account. You must specify a unique username, a secure password, an assigned department, and an appropriate access role. Use the Pencil icon on the table to update these details later.

2. User Roles Overview

Superadmin Full system access and user management.

Admin Manage scheduling data and resources.

User View-only access and reporting.

3. Finding & Sorting
  • Search Bar: Type any username to find specific accounts instantly.
  • Funnel Icon: Filter the accounts by User Role (Superadmin, Admin, User).
  • Sort Menu: Arrange the user list by Username (A-Z) or view the Newest accounts first using the dropdown on the top-right.
4. Managing & Mass Actions

Each row has icons for individual actions. To handle multiple users:

  • Pencil Icon: Edit the user's role, password, or department assignment.
  • Trash Icon: Move the user account to the Recycle Bin safely.
  • Bulk Actions: Click any row to select it (or the Header box to Select All). Use the Green Bar to bulk-delete users to the Recycle Bin.
5. Pagination

Navigate between pages using the Page Numbers or the Previous/Next buttons at the bottom. For larger lists, enter a page number into the 'Jump to' box to go there instantly. You can also use your keyboard's Left/Right arrow keys to flip through pages.
