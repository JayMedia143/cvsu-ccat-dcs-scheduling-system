    Schedule Editor Guide
    {% if session.get('role') in ['admin', 'superadmin'] %}
    1. HOW TO EDIT
    Direct Mode

    Use this to change the schedule right away. The Official Schedule will update for all users to see immediately.

    Draft Mode

    Use this to plan privately. No one sees your work until you click the Publish button. This is safe for making big changes.

    2. SAVING YOUR WORK
    Save as Draft (Direct Mode)

    If you are in Direct Mode, click this to save the current live schedule as a new draft version.

    Save as Copy (Draft Mode)

    If you are in Draft Mode, click this to create a duplicate of your current work to try a different version.

    3. HOW TO ADD A SCHEDULE

    There are two ways to add a schedule:

    A. Click the Line:

    Click any blank line in the schedule grid. This will automatically set the Day and Time for you in the form.

    B. Manual Entry:

    Pick the Course, Section, and Teacher from the dropdown lists. Then, click the Add Schedule button to save.

    4. BUTTONS
    Preview Mode

    Click the Eye icon to see the final look of your schedule. Use this to check for errors before you finish.

    Sync Grid

    Click this to keep your work updated with any new changes from the main system.

    Back and Forward Arrows: Use these arrows to go back or fix a mistake quickly.
    5. MANAGE YOUR DRAFTS
    Gray Check Icon: Use this to pick a draft and start working on it.
    Green Pencil Icon: Use this to change the draft info or name.
    Trash Icon: Use this to remove old drafts that you do not need anymore.
