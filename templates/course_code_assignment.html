Department Assignment Guide
1. Prefix Rules (Group Mapping)

Map a code prefix (like COSC or Math) to a department. This automatically assigns every subject starting with that code to the chosen department instantly.

2. Code Exceptions (Overrides)

Use this to override a prefix rule for a single subject. For example, if all MATH subjects belong to one department but MATH 10 belongs to another, add MATH 10 as an exception.

3. Previewing Subjects

Click any Blue or Yellow badge (the subject codes) to see exactly which courses will be affected. This lets you double-check the impact before saving your changes.

4. Unassigned & New Rules

Yellow rows represent prefixes that haven't been assigned yet. You can also manually add new rules by typing a prefix or code and clicking the Search icon to scan for matches.

5. Saving & System Updates

Changes are not final until you click the floating green 'Save & Apply' button at the bottom right. This scans all courses and updates their department data across the entire system.
